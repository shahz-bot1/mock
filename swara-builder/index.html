Swara Builder Playground4 prototypes · Adi tala only · review + pick a direction

P1 · structured

Adi Grid

Rows of 8 beat-slots (one avarta each). Tap a slot → raga-aware picker. Beats hold stacks (rsN in one beat), holds (,), gaps (–). Adi anga dividers (4+2+2). Playback highlights beats in sync.

 P2 · notation

Composition

Geetham-style: Pallavi / Anupallavi / Charanams. Type swara tokens (S R2 G3 , –, stacks with +, low octave .S), bars auto-mark every 8 beats, optional sahitya line under.

 P3 · free-time

Flow Strip

No grid at all. Append swara chips; each chip owns its duration (¼ → 2 beats). For phrases that refuse to sit in 8. Same picker, same playback engine, variable timing.

 P4 · capture

Tap-Along

A demo phrase loops (4 cycles) while you tap swara pads in time. Taps quantize to the beat grid — multiple taps per beat become stacks. Fastest way to capture a phrase you can already hear.

What to compare

· Entry speed: which one gets a phrase down fastest?
· Grid vs free: does the 8-beat avarta help (P1) or fight you (P3)?
· Gaps: every prototype treats gaps as first-class — is that enough?
· Stacks: try rsN in one beat on P1/P2 — does the playback subdivision sound right?
· The winner gets ported into RagaMentor as the loop swara builder. Mix-and-match is allowed — e.g. P4's capture feeding P1's grid.
